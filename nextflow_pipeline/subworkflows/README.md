## Naming convention

1_2_3_[subworkflowname].nf

1. Input type
s = sample
g = genome/s
xs = cross sample (eg.g. mash)
f = fasta (1 large fasta/q file)

2. Sequencing technology
i = Illumina
o = Oxford nanopore
p = PacBio

3. Sample type
mg = metagenomes
mt = metatranscriptomes
mp = metaproteomes
mb = metabolomes
g = genomes
t = transcriptomes
p = proteomes

Subbworkflow name:
Short description of what the subworkflow does.
